LOCAL CONTEXT

Malaysia market signals

Published DOSM observations for the selected career. These are historical online recruitment statistics, kept separate from skill trends and scenario scores. Missing records are not zero demand.

Sources, calculation and update method

Trend codes: Rising +1, Stable 0, Declining −1, Unknown 0. Trend adjustment = 10 × the average code across all required skills. Scenario score = skill coverage + multiplier × trend adjustment, limited to 0–100. Unknowns stay in the denominator.

Data is manually reviewed against public publications and reloaded on every analysis request. Data updated is the curator's review date, not a live sync timestamp. Newer publications require a dataset review; sources are not automatically synchronised from the web.

Missing or invalid trend evidence contributes zero adjustment. A trend-file failure falls back to skill coverage ranking. The same career order in both scenarios can be a valid result.
